# Kennedy Mwangi — QA Portfolio

Professional Quality Assurance / Quality Engineering portfolio for Kennedy Mwangi.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
- GitHub Actions

## Local preview
Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## CV generation
The downloadable CV is generated by `scripts/generate_cv.py` and written to `output/pdf/Kennedy-Mwangi-QA-CV.pdf`.

## Deployment
The repository includes `.github/workflows/pages.yml`. Every push to `main` deploys the static site to GitHub Pages once Pages is configured to use **GitHub Actions** as its source.
